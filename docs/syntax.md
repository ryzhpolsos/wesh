## Введение
Язык программирования wesh основан на двух сущностях - _командах_ и _аргументах_. Всё остальное является лишь их разновидностями, в качестве отдельной сущности выступают только _комментарии_.

## Комментарии
Комментарий - любая строка, первый не-пробельный символ которой - символ `#`. Пример:
```
    # это комментарий
#и это тоже комментарий
```

## Команды
Команда - основной синтаксический элемент wesh. Любая команда принимает 0 или более аргументов и возвращает результат (результат может быть пустой строкой или значением null). Команды разделяются переводом строки и/или точкой с запятой (`;`).

Существуют следующие виды команд:
- **Встроенные команды**: встроенные в ЯП команды. К ним относятся также условия (`if`), циклы (`while`, `for`) и прочие конструкции, в других ЯП обычно выделяемые в отдельные синтаксические сущности;
- **Функции**: функции вызываются так же, как и команды;
- **Выражения**: арифметические, логические и др.

Стоит отметить, что к командам также применяется _парсер аргументов_.

### Выражения
Существуют следующие виды выражений:
- **Числовые**: любые десятичные числа (`0`, `15`, `-4.27`);
- **Строковые**: строки, заключённые в кавычки (`'test string'`, `"foo"`);
- **Арифметические**: арифметические выражения. Доступные операции - `+` (сложение), `-` (вычитание), `*` (умножение), `/` (деление), `%` (остаток от деления), `()` (скобки);
- **Логические**: логические выражения. Результат - `true` или `false`. Доступные операции - `=` (равно), `<>` (не равно), `<` (меньше), `>` (больше), `<=` (меньше или равно), `>=` (больше или равно), `||` (или), `&&` (и), `!` (не), `()` (скобки);
- **Выражения присваивания**: выражения вида `переменная = значение`. Значение может быть любой командой (включая константные выражения);
- **Константные**: допустимые в особых случаях (например, после `return`) строки без кавычек.

## Аргументы
Аргументы отделяются от команды пробелом, а друг от друга - запятой и пробелом или только пробелом. Пример: `command arg1, arg2`

Выделяются следующие типы аргументов:
- **Литералы**: любые последовательности символов, не содержащие запятых и пробелов (`5`, `-7.42`, `foo`, `bar_baz`);
- **Константные строки**: выделяются одиночными кавычками (`'`). Можно использовать `\'` для экранирования кавычки внутри строки (`'foo'`, `'I\'m a string'`);
- **Расширяемые строки**: выделяются двойными кавычками (`"`). Можно использовать `\"` для экранирования кавычки внутри строки. Поддерживают [интерполяцию строк](#интерполяция-строк) (`"foo"`, `"value is @val"`);
- **Переменные**: в начале аргумента находится символ `@`, а за ним - имя переменной (`@val`, `@userName`). Получают значение переменной;
- **Подкоманды**: выделяются круглыми скобками (`()`). Получают результат выполнения команды, указанной в скобках;
- **Блоки кода**: выделяются фигурными скобками (`{}`). Применяются для передачи команде кода.

### Интерполяция строк
Интерполяция строк - вставка значений переменных и выражений внутрь строки. Интерполяцию поддерживают только строки в двойных кавычках (`"`).

- **Вставка значения переменной**: производится с помощью оператора `@variableName` (`"value is @val"`, `"Hello, @userName"`) или `@{variableName}` (`"value is @{val}"`, `"Hello, @{userName}"`). Второй оператор удобен, когда сразу после места вставки значения переменной находятся другие символы, которые могут быть восприняты как часть имени переменной;
- **Вставка результата выполнения команды**: производится с помощью оператора `&{command}` (`"value is &{2 + 2}"`).
