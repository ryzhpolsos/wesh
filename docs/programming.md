## Основы составления скриптов
Скрипты на wesh состоят из команд, исполняемых поочерёдно. По умолчанию каждая команда занимает одну строку, однако блоки кода могут занимать несколько строк.

## Ввод и вывод на консоль
Для большей простоты и наглядности в этой статье будут использоваться некоторые команды ввода/вывода на консоль. Вот их краткое описание:
- `writeln`: печатает на консоль свой первый аргумент. Примеры: `writeln "foo"`, `writeln 5`;
- `readln`: читает и возвращает с консоли строку. Пример: `result = readln`.

## Hello World
Код для вывода "Hello World!" на консоль выглядит так:
```
writeln 'Hello World!'
```

## Переменные
Переменные в wesh не имеют типа и определяются неявно при первом присваивании.

Присваивание переменной значения:
```
foo = 5
```
Вывод значения переменной на консоль:
```
writeln @foo
```

Имя переменной может содержать латинские буквы, цифры, символы дефиса (`-`) и нижнего подчёркивания (`_`).

Переменные всегда определяются в пределах блока, в котором происходит определение. Если определение происходит вне блока, переменная становится глобальной.
```
globalVar = 5

# Блок кода для примера
if true {
    localVar = 6

    # Выведет "Global: 5, local: 6", т.к. глобальные переменные доступны во всех блоках
    writeln "Global: @globalVar, local: @localVar"
}

# Выведет "Global: 5, local: ", т.к. локальные переменные не доступны вне блока, где они были определены
writeln "Global: @globalVar, local: @localVar"
```

## Условия
Условия в wesh представлены командой `if`. Самый простой способ создания условия:
```
if условие {
    код
}
```
_условие_ - команда или логическое выражение, _код_ - код, который выполнится, если условие соблюдено (равно `true`).

Существует также возможность определить действия на случай невыполнения условия:
```
if условие {
    true-код
} else {
    false-код
}
```
В данном варианте _true-код_ выполнится, если условие соблюдено, а _false-код_ - если не соблюдено.

Поддерживаются промежуточные условия:
```
if условие1 {
    условие1-соблюдено
} elif условие2 {
    условие2-соблюдено
} elif условие3 {
    условие3-соблюдено
} else {
    по-умолчанию
}
```
Теперь команда будет по очереди проверять условия и вызовет соответствующий блок кода. Если ни одно из условий не будет соблюдено, вызовется else-блок (параметр _по-умолчанию_ в примере)

Пример использования условий:
```
writeln 'Введите свой возраст'
age = readln
```

## Циклы
wesh поддерживает два вида циклов - `while` и `for`.

Цикл `while`:
```
while условие {
    код
}
```
_код_ будет выполняться, пока истинно _условие_. Условие проверяется каждую итерацию.
