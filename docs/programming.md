## Основы составления скриптов
Скрипты на wesh состоят из команд, исполняемых поочерёдно. По умолчанию каждая команда занимает одну строку, однако блоки кода могут занимать несколько строк.

## Ввод и вывод на консоль
Для большей простоты и наглядности в этой статье будут использоваться некоторые команды ввода/вывода на консоль. Вот их краткое описание:
- `writeln`: печатает на консоль свой первый аргумент. Примеры: `writeln "foo"`, `writeln 5`;
- `readln`: читает и возвращает с консоли строку. Пример: `result = readln`.

## Hello World
Код для вывода "Hello World!" на консоль выглядит так:
```
writeln 'Hello World!'
```

## Переменные
Переменные в wesh не имеют типа и определяются неявно при первом присваивании.

Присваивание переменной значения:
```
foo = 5
```
Вывод значения переменной на консоль:
```
writeln @foo
```

Имя переменной может содержать латинские буквы, цифры, символы дефиса (`-`) и нижнего подчёркивания (`_`).

Переменные всегда определяются в пределах блока, в котором происходит определение. Если определение происходит вне блока, переменная становится глобальной.
```
globalVar = 5

# Блок кода для примера
if true {
    localVar = 6

    # Выведет "Global: 5, local: 6", т.к. глобальные переменные доступны во всех блоках
    writeln "Global: @globalVar, local: @localVar"
}

# Выведет "Global: 5, local: ", т.к. локальные переменные не доступны вне блока, где они были определены
writeln "Global: @globalVar, local: @localVar"
```

## Условия
Условия в wesh представлены командой `if`. Самый простой способ создания условия:
```
if условие {
    код
}
```
_условие_ - команда или логическое выражение, _код_ - код, который выполнится, если условие соблюдено (равно `true`).

Существует также возможность определить действия на случай невыполнения условия:
```
if условие {
    true-код
} else {
    false-код
}
```
В данном варианте _true-код_ выполнится, если условие соблюдено, а _false-код_ - если не соблюдено.

Поддерживаются промежуточные условия:
```
if условие1 {
    условие1-соблюдено
} elif условие2 {
    условие2-соблюдено
} elif условие3 {
    условие3-соблюдено
} else {
    по-умолчанию
}
```
Теперь команда будет по очереди проверять условия и вызовет соответствующий блок кода. Если ни одно из условий не будет соблюдено, вызовется else-блок (параметр _по-умолчанию_ в примере)

Пример использования условий:
```
writeln 'Введите число'
number = readln

if {@number = 0} {
    writeln 'Число равно нулю'
} elif {@number % 2 = 0} {
    writeln 'Число чётное'
} else {
    writeln 'Число нечётное'
}
```

## Циклы
wesh поддерживает два вида циклов - `while` и `for`.

### Цикл `while`
```
while условие {
    код
}
```
_код_ будет выполняться, пока истинно _условие_. Условие проверяется каждую итерацию.

Пример цикла `while`:
```
i = 0

while {@i < 10} {
    writeln @i
    i = @i + 1
}
```
Будут выведены числа от 0 до 9.

### Цикл `for`
```
for {инициализация} {условие} {финальное выражение} {
    код
}
```
Перед началом цикла выполнится _инициализация_ (обычно в этом блоке создаётся переменная-счётчик). Перед каждой итерацией проверяется _условие_, если оно истинно, то выполняется сначала _код_, а затем - _финальное выражение_.

Пример цикла for:
```
for {i = 0} {@i < 10} {i = @i + 1} {
    writeln @i
}
```
Будут выведены числа от 0 до 9.

## Функции
Функции определяются командой `func`:
```
func название список-аргументов {
    код
}
```
Аргументы перечисляются через запятую, в коде функции доступны переменные с именами, соответствующими названиям аргументов. Также внутри функции доступен массив `args`, содержащий все переданные аргументы.

Функции могут содержать команду `return`, принимающую единственный аргумент - любое выражение. Выполнение функции после команды `return` прекращается, а значение выражения становится результатом её выполнения.

Пример определения функции:
```
func add a, b {
    return @a + @b
}
```

Вызвать функцию можно по названию:
```
add 5, 6
```

Также доступны анонимные функции. Они не имеют имени, а для их вызова используется значение, возвращённое командой `afunc`, используемой для определения анонимной функции.

Пример создания и вызова анонимной функции:
```
add = afunc a, b {
    return @a + @b
}

@add 5, 6
```
Обратите внимание, что в последней строке вызывается переменная `add`, содержащая анонимную функцию.

## Объекты
Объекты - контейнеры, содержащие свойства и методы. Для доступа к свойствам и методам применяется точечная нотация (`@объект.свойство`), а для их установки - конструкция `объект.свойство = значение`, где _значение_ - любая команда или выражение (включая константные выражения).

### Создание объектов
Пустой объект можно создать тремя командами: `obj.create`, `object` и `new Object`. Последний вариант является предпочтительным.

Пример создания и использования объекта:
```
# Создание объекта
obj = new Object

# Установка свойства объекта
obj.foo = 'bar'

# Вывод значения свойства
writeln @obj.foo
# Выведет "bar"
```

Если после создания объект нужно сразу заполнить свойствами, можно использовать команду `createObject`. Она принимает в качестве аргумента блок кода и возвращает объект со свойствами, установленными соответственно определённым в блоке кода переменным.

Пример создания объекта с помощью этой команды:
```
# Создание наполненного свойствами объекта
obj = createObject {
    foo = 5
    bar = 6
}

writeln (@obj.foo + @obj.bar)
# Выведет "11"
```

### Методы
Метод объекта - анонимная функция, являющаяся свойством объекта. Методы определяются и вызываются точно так же, как и анонимные функции.

Пример:
```
# Создание объекта
calc = new Object

# Создание метода объекта
calc.add = afunc a, b {
    return @a + @b
}

# Вызов метода и вывод результата
writeln (@calc.add 5, 6)
# Выведет "11"
```

## Массивы
Массивы - особый вид объектов, вместо именованных свойств в них применяются числовые индексы. Первый элемент массива имеет индекс `0`.

### Элементы массива
Доступ к элементам осуществляется при помощи точечной нотации (`@массив.индекс`), а изменение элементов - при помощи конструкции `массив.индекс = значение`, где _значение_ - любая команда или выражение (включая константные выражения).

Пример:
```
# Получение элемента с индексом 2
writeln @arr.2

# Установка значения элемента с индексом 2
arr.2 = 'test'
```

Также существуют методы `get` и `set` для работы с переменными индексами:
```
index = 2

# Получение элемента
writeln (@arr.get @index)

# Установка значения элемента
@arr.set @index, 'test'
```

### Создание массива
Массив можно создать тремя командами - `arr.create`, `array` или `new Array`. Все эти команды принимают список элементов, которыми нужно заполнить массив. Последний вариант является предпочтительным.

Пример создания и использования массива:
```
# Создание массива
arr = new Array foo, bar, baz

writeln @arr.0
# Выведет "foo"

writeln @arr.1
# Выведет "bar"

writeln @arr.2
# Выведет "baz"
```

### Длина массива
Длина массива - количество элементов, находящихся в массиве. Получить длину массива можно, обратившись к свойству `length`.

Пример:
```
arr = new Array foo, bar, baz

writeln @arr.length
# Выведет "3"
```

### Добавление элемента в массив
Можно добавить в массив элемент, используя метод `add`. Метод принимает в качестве единственного аргумента элемент, который необходимо добавить.

Пример:
```
arr = new Array foo, bar

writeln @arr.length
# Выведет "2"

# Добавление в массив элемента "baz"
@arr.add baz

writeln @arr.length
# Выведет "3"

writeln @arr.2
# Выведет "baz"
```
