# `obj.set`

## Синтаксис
```
obj.set <объект>, <свойство>, <значение>
```

- **объект**: объект, свойству которого необходимо присвоить значение;
- **свойство**: название изменяемого свойства объекта;
- **значение**: новое значение для свойства объекта.

Устанавливает значение указанного свойства объекта. Эта команда полезна, когда название свойства формируется программно.

## Примеры
```
myObj = new Object

propName = 'foo'
obj.set @myObj, @propName, 'bar'

writeln @myObj.foo
```
Установка значения свойству, название которого содержится в переменной.
