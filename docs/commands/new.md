# `new`

## Синтаксис
```
new <тип объекта> [...параметры]
```

- **тип объекта**: один из представленных ниже типов объекта;
- **параметры**: параметры, передаваемые объекту. Зависят от типа объекта.


### Типы объектов
```
new Object
```
Возвращает пустой объект.

---

```
new Array [...элементы]
```
- **элементы**: список элементов массива.

Возвращает массив с указанными элементами или пустой массив, если элементы не указаны.

---

```
new NetObject <класс> [...аргументы конструктора]
```
- **класс**: полное название класса;
- **аргументы конструктора**: список аргументов, передаваемый конструктору объекта.

Создаёт и возвращает экземпляр указанного класса .NET, передав конструктору указанные аргументы.

---

```
new NetClass <класс>
```
- **класс**: полное название класса.

Возвращает объект, содержащий статические свойства и методы класса .NET.

## Примеры
```
obj = new Object
obj.foo = 'bar'
writeln @obj.foo
```
Создание и использование объекта.
<br><br>

```
arr = new Array foo, bar, baz
writeln @arr.2
```
Создание и использование массива.
<br><br>

```
form = new NetObject System.Windows.Forms.Form
@form.ShowDialog
```
Создание и открытие формы WinForms.
<br><br>

```
guid = new NetClass System.Guid
newGuid = @guid.NewGuid
writeln @newGuid.ToString
```
Генерация случайного GUID.
