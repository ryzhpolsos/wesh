# `obj.get`

## Синтаксис
```
obj.get <объект>, <свойство>
```

- **объект**: объект, свойство которого необходимо получить;
- **свойство**: название получаемого свойства объекта.

Возвращает указанное свойство объекта. Эта команда полезна, когда название свойства формируется программно.

## Примеры
```
myObj = new Object
myObj.foo = 'bar'

propName = 'foo'
writeln (obj.get @myObj, @propName)
```
Вывод свойства, название которого содержится в переменной.
