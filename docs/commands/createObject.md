# `createObject`

## Синтаксис
```
createObject <блок кода>
```

- **блок кода**: блок кода, согласно определённым в котором переменным будут установлены свойства объекта.

Создаёт и возвращает объект со свойствами, установленными соответственно определённым в блоке кода переменным.

## Примеры
```
myObj = createObject {
    foo = 5
    bar = 6
}

writeln (@obj.foo + @obj.bar)
```
Создание объекта и вывод суммы двух его свойств.
