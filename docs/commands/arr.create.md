# `arr.create`

## Синтаксис
```
arr.create [...элементы массива]
```

- **элементы массива**: список элементов, которые необходимо добавить в массив.

Создаёт массив с указанными элементами или пустой массив, если элементы не указаны.

## Примеры
```
# Создание массива
arr = arr.create foo, bar, baz

writeln @arr.0
writeln @arr.1
writeln @arr.2
```
Создание массива с тремя элементами и вывод элементов.
