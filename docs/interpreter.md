## Загрузка и установка
Скачать интерпретатор можно на [странице релизов](https://github.com/ryzhpolsos/wesh/releases). Для 64-битных систем скачивайте файл `wesh.exe`, а для 32-битных - `wesh_x86.exe`.

Интерпретатор не требует установки и является портативным, достаточно лишь поместить исполняемый файл в удобное место. Если Вы скачали 32-битную версию, рекомендуется переименовать `wesh_x86.exe` в `wesh.exe` во избежание путаницы.

## Синтаксис командной строки
На данный момент интерпретатор wesh поддерживает 2 режима - интерактивный (REPL) и запуск скрипта.

### REPL
Для открытия REPL запустите `wesh.exe` без параметров. Приглашение командной строки сменится на `[wesh] >` и Вы сможете вводить команды, результат выполнения которых будет показан в консоли. Для выхода из REPL используйте сочетание клавиш `Ctrl+C`.

Пример работы с REPL:
```
D:\Downloads> wesh
[wesh] > a = 5
5
[wesh] > b = 6
6
[wesh] > @a + @b
11
```

### Запуск скриптов
Для запуска скрипта передайте путь к файлу скрипта интерпретатору:
```
wesh path\to\script.wesh
```
Результаты выполнения команд скрипта не выводятся на консоль. Для вывода необходимых данных используйте команду `writeln`.
