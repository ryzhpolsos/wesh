# wesh

## Описание
wesh - гибкий скриптовый язык для разработки под Windows, написанный на C#. Некоторые его возможности:
- Работа с платформой .NET
- Вызов функций WinAPI и внешних DLL
- Автоматизация работы с окнами и приложениями
- Установка горячих клавиш, симуляция ввода

На данный момент в активной разработке находится версия wesh 3.0. Более старые версии размещены в [этом репозитории](https://github.com/nekit270ch/wesh).
